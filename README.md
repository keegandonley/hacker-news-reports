# The Hacker Herald — Edition Archive

**The Hacker Herald** is a broadsheet newspaper typeset from the Hacker News front page, published twice daily (weekdays) for a single reader: Keegan. This repository is the paper's permanent archive — one self-contained folder per edition (HTML + images), browsable on GitHub or via GitHub Pages.

- **Latest edition (live site):** https://merry-photon-qmu3.sites.littleplanetlabs.dev/
- **This archive on Pages:** https://keegandonley.github.io/hacker-news-reports/
- **How it's made:** see [PROCESS.md](PROCESS.md) — the full operating manual for the automated newsroom.
